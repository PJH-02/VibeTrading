## Objective

The orchestrator writes metadata and accepts work.

## Implementation instructions
1. CLI `python3 scripts/dev/agent_task.py --root PATH list-ready` returns the existing status projection. `packet TASK_ID --spec JSON_PATH` emits a validated JSON TaskPacket. Public `make_packet(root: Path, task_id: str, spec: dict) -> dict`. Spec is Codex-authored, not inferred by worker: required keys objective (nonempty string), read_paths (list[str]), edit_paths (list[str]), forbidden_paths (list[str]), contract_ids (list[str]), implementation_steps/acceptance/test_commands/stop_conditions (nonempty list[str]), review_severity (low|normal|critical), profile and model. Packet adds task_id, current exact git base_sha, exact canonical prerequisites, source_hashes for ALL read/edit paths (sha256 or null for new edit files), canonical_hashes, qualified route/provider. Require task READY from R01 (paused/blocked/running/external/pending-acceptance must reject). Require git HEAD and fail if unknown. Models must be present in canonical profile AND have exact model_readiness entry status QUALIFIED_O00; preserve selected exact ID. No fallback, no acceptance by catalog alone.
2. All paths must be concrete normalized POSIX relative paths, no glob, traversal, absolute/Windows paths, empty/dot, symlink in any existing component (even internal symlinks). Block .git/.env*, secrets, runtime_data, .ssh/.aws, credential filenames and key/pem files at any depth. Existing read paths must be regular files. Missing edit path may be ADD; its existing ancestors must be safe. For original VN/TX edits, require subset of canonical edit_paths.path; permit historical action ADD when file already exists (the current pinned hash resolves reality), never permit an out-of-scope product file. Caller forbidden patterns must include all canonical forbidden_paths (including prose restrictions); reject concrete paths matching actual forbidden globs. For R/O require canonical concrete edit_paths registration; absent scope fails closed. No writes in make_packet. Canonical contracts must be preserved as subset of contract_ids. Keep packet size reasonable; no embedding metadata or source text.
3. `check_scope(snapshot: dict[str, str|None], after: dict[str,str|None], allowed: list[str]) -> list[str]` returns sorted changed paths only if all changes are allowed; reject unsafe paths and out-of-scope changes including untracked/deletions. Do not trust Git status alone. `verify_source(root,packet)` revalidates current HEAD, both canonical hashes and every pinned source hash; concurrent source edits fail. Public hash/snapshot helpers if useful. No TOCTOU claims beyond caller lock and recheck.
4. `check_tests(commands: list[str], results: list[dict]) -> dict` verifies nonempty exact ordered commands; each result must have exact command and true int exit_code (bool invalid), zero exit, and stdout_sha256 a 64-lowercase-hex digest of actual host output. Results cannot omit tests or invent extra commands. Return VERIFIED_TESTS, never ACCEPTED. Host sandbox collects these results later; do not mistake any caller-supplied JSON for trusted evidence.
5. `classify_failure(exit_code, text)` returns one of PROVIDER_RATE_LIMIT, AUTH_FAILURE, MODEL_TOOL_FAILURE, EXECUTION_TIMEOUT, TEST_FAILURE, CONTRACT_VIOLATION, SCOPE_VIOLATION, EXTERNAL_ONLY, SAFETY_BLOCKER. Clear rate/auth/timeout patterns first; arbitrary worker failure -> MODEL_TOOL_FAILURE. No automatic retry/model switch. `handoff(packet)` returns bounded summary of objective/scopes/exact test commands + statement Codex review/independent tests required. `write_record(state_dir, packet, results, *, decision)` only permits decision='PENDING_CODEX_REVIEW', stores append-only unique private JSON receipt (dir0700 file0600), hashes canonical packet+results, never changes canonical status or records PASS/ACCEPTED from worker assertions. CLI record can use packet/results JSON inputs but explicitly marks provenance UNTRUSTED_INPUT until later host execution attestation. No fake trusted-receipt API.
6. CLI packet/check-scope/check-tests/record/handoff expose the corresponding functions with explicit JSON inputs and meaningful nonzero failure exits; argparse help. Robust malformed JSON handling, stdlib only. Import works as scripts.dev.agent_task and when run by path. No command execution except read-only git HEAD via argument vector.

## Acceptance criteria / exact tests

Cover valid READY packets and exact hashes; false/paused/running/external/pending prerequisite refusal; unqualified or wrong profile model; original scope+contracts/forbidden retention; missing R/O scope; symlink/traversal/Windows/glob/secret denial; source changed with same HEAD; modified canonical hashes; scope deletions/untracked; empty/failed/bool/incomplete tests; nonaccepting receipt private permissions/unique paths; failure classification; real CLI list-ready and malformed inputs. Prefer 15–30 focused real tests with parametrization, not excessive wrappers. Do not mirror only implementation happy paths.
