## Bounded proof contract
1. Add an immutable factory-issued RetainedPrefix proof and capture_retained_prefix(root, producer_id, incarnation, *, first_retained_segment, generation, consumer_cursors, max_disk_bytes, max_records, max_frame_bytes, max_header_bytes). Reuse existing frame hashing, scan_spool and producer checkpoint v1. No new spool format or writer behavior. Capture is READ ONLY, while the FULL original prefix exists, with no uncertainty; never infer a base from the first file present. Require a nonzero removed prefix, first retained file sealed/nonempty, valid contiguous entire stream, durable checkpoint covering the cut, and a nonempty bounded tuple (max17) of explicitly confirmed consumer SpoolCursors with matching identity and sequence >= base. Slowest consumer pins the oldest needed range. No pruning API.
2. Proof pins producer/incarnation, explicit nonempty generation (max128 UTF8 bytes), base sequence and base payload SHA256 (the last record of the previous sealed segment), first retained segment ID, exact first retained sealed segment byte SHA256, SHA256 chain over complete prefix segment IDs/hashes through the first retained segment, producer checkpoint file SHA256 and its captured durable sequence. Bounds use existing max_records/max_disk_bytes; hash files in chunks, never load whole segments/history in RAM. All removed segments must be sealed. First retained frame must be base+1. This is trusted-owner pre-retention provenance, NOT remote/archive/GC approval or cryptographic authenticity against a malicious owner.
3. Proof canonical serialization to_bytes() and RetainedPrefix.from_bytes(payload, *, expected_sha256, expected_generation), bounded <=8192 bytes, strict exact version2 schema, duplicate/nonfinite/type/digest/identity checks and immutable private factory marker (plain dict or dataclass.replace must not bypass validation). The expected hash/generation are independent owner-pinned inputs, never auto-read/auto-trusted from the spool. Forged/torn/mismatched proofs rejected. The prefix chain is committed by the independently pinned proof hash; missing original prefix cannot be retroactively certified. There is no proof file written/loaded automatically in a spool directory.
4. Add optional retained_prefix=None to scan_spool, read_spool_records, SpoolReader. Default v1 unchanged. A nonzero base is accepted ONLY with an explicit valid proof and explicit after cursor >=base (reader/iterator); no default cursor skip. Inventory requires the actual first segment ID exactly equals proof.first_retained_segment, contiguous IDs thereafter, only final active, no empty sealed, byte/record/count bounds. v2 max_records bounds RETAINED record count, not absolute cursor/segment IDs; absolute base and IDs must be finite nonbool positive ints with upper bound <=2**63-1. Add backward-compatible default fields/properties to SpoolScan for base_sequence/first_segment_id/last_segment_id as needed; segment_count means actual count, last_sequence remains absolute. Never rewrite existing frames, checkpoint v1, base or cursor numbering.
5. Verify the first retained file SHA against proof, exact first sequence, checkpoint producer/incarnation, durable >= captured durable and >=base; at equal captured durable require exact captured checkpoint-file SHA. Further actual durable growth is allowed only via the existing v1 checkpoint parser and verified contiguous frames; no regression. A stale/mismatched generation/proof is rejected at deserialization. Reader retains its selected immutable proof; no implicit generation switch. SpoolReader uses the selected start ID for startup locate and subsequent inventory, poll only new offsets, preserve sticky error/no partial-batch publication and inode/shrink/sealed-signature checks. Recheck anchor identity/hash before publishing each nonempty batch (bounded streaming, document cost); detect replaced/modified anchor, missing/interior gap or backwards checkpoint. Short/torn active tail or unfinished checkpoint at initial retained startup fails closed; default v1 behavior stays unchanged. Neither reader nor proof grants LIVE/READY authority. Writer must still reject a retained directory without changing existing writer defaults.

## Storage reuse seam

Unknown keys/identity/type fail before shared writer work; no plan/config/deployment wiring. Existing no-option behavior identical. Use existing local_progress and RuntimeStore delivery_committed/fact verification; do NOT reset progress or create progress at the base.

Do not fabricate a SpoolRecord from absent input or skip attestation. Any mismatch fails before new delivery/progress; preserve existing DB/parquet bytes and quarantine rules.
Existing storage mutation/recovery classification and healthy lanes stay compatible. Storage never authorizes GC or assumes every other consumer has advanced.
