# Telegram 명령 분리 및 잘못 전환된 메인 서버 복구

2026-10-14 21:05 KST 검증. 대상은 VibeTrading 메인 서버 `49.50.141.106`이다.

## 무응답 원인과 복구

별도 Codex 채팅 ‘백테스트 개발 계획 수립’의 Oracle 신청 루프 배포가 micro 서버 `49.50.141.25` 대신 메인 서버를 대상으로 실행됐다. 20:16경 VibeTrading 컨테이너가 중단됐고, 실행 코드와 배포 디렉터리 및 운영 컨테이너가 삭제됐으며 Docker도 비활성화됐다. Telegram 명령 처리 프로세스 자체가 없는 것이 이번 무응답의 직접 원인이다.

사용자의 롤백 지시에 따라 메인 서버 Oracle 루프를 중지하고 자동 시작을 해제했다. 보존된 Docker 기반 이미지와 로컬 현재 소스, 서버에 남아 있는 설정·디스크·NATS·원장·CSV를 사용해 기능을 복구했다. 삭제된 기존 이미지와 실행 디렉터리의 바이트 단위 원상복구를 뜻하지 않는다.

- 실행 서비스 14개: NATS, 국내 수집기, 국내 저장·보관, Telegram, 코인 수집기 3개, 코인 저장·보관, ETF 모의매매, ETF CSV 동기화, 대시보드 브리지·조회 워커.
- `vibetrading`, `vibetrading-etf-mock`, `vibetrading-etf-csv-sync`, `vibetrading-monitor` systemd 유닛을 활성화해 재부팅 뒤에도 실행한다.
- Bitget·Bybit 수집기는 제외했다. Binance·Arcus·Grvt에서 BTC/ETH/SOL 수신을 각각 확인했다.
- KIS·Kiwoom·TOSS는 검증 시각에 정상적인 장 종료 대기 상태였다.
- 두 모의계좌 연결과 기존 ETF별 계좌 경로를 확인했고 미체결은 0건이다. 복구 과정에서 주문을 제출하지 않았다.
- 기존 ETF 일봉·분봉 8개 및 KOSPI200·S&P500 일봉 2개의 체크섬을 검증했다. 국내 마지막 일자는 2026-10-14, S&P500은 완료된 미국 세션 2026-10-13이다.
- 삭제된 대시보드 암호화 개인 키는 재생성해 보존 데이터 디스크에 두었다. 대시보드에 별도로 등록된 추가 계정은 0개였다.

## 명령

`status`, `/status`, `/status@봇이름`은 수집기별 상태, 최근 실제 수신 종목, 설정 종목을 표시한다. 국내 수신 기준은 최근 120초다. 특정 코인 거래소의 상태가 오래됐더라도 다른 거래소의 정상 수신 종목은 표시한다.

`trade`, `/trade`, `/trade@봇이름`은 종목별로 한 줄을 사용하고 실제/가정 체결을 구분해 매수·매도 수량과 평균 체결가를 표시한다. 그 다음 두 줄은 당일 및 전체 기록기간의 순수익·수수료다. 실제 순수익과 실제+가정 합계를 구분하고, 가정 수수료는 추정임을 표시한다.

두 모의계좌의 일별 체결 조회를 페이지 끝까지 읽고 별도 `broker_trades` 테이블에 저장한다. 이 조회가 완료되면 원장 체결·검증 주문을 다시 더하지 않아 중복 집계하지 않는다. 계좌에서 직접 실행된 당일 거래도 포함한다. 조회 조건은 [KIS 공식 일별 체결 조회 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_ccld/inquire_daily_ccld.py)를 따른다.

장중 계좌 평가 스냅샷을 60초 간격으로 저장하고 명령 응답에는 저장 시각을 표시한다. 장 마감 보고가 있으면 이후 잔고 조회의 당일 손익·비용 0 반환으로 덮어쓰지 않는다. 실제로 복구 검증 중 야간 조회에서 두 값이 0으로 반환돼 이 회귀를 확인하고 방지했다. 전체기간은 보유한 일별 평가 기록의 합계이며 최초 기록일·최근 기록일을 표시한다. 일별 평가 누락이나 조회 불가는 0원으로 꾸미지 않는다.

현재 기록기간은 2026-10-14 하루다. 확정 실제 계좌 순수익 -135원, KIS 제비용 40원, 실제+가정 순수익 -882,709.46754원, 실제+가정 비용 17,459.46754원이다. 실제 계좌 체결은 6개 주문이며, 기존 권한 거절 가정 체결은 4건이다.

이 수치는 서버 복구 당시 원본 계좌 합계다. 이후 사용자가 오늘 실제 체결 6건을 테스트로 지정해 보고에서 제외했다. 현재 표시 손익·수수료 및 069500 신호 구분은 [테스트 제외 변경 기록](TRADE_TEST_EXCLUSION_2026-10-14.md)을 따른다.

## 알림 및 수신 안정성

수집기의 정상 시작·종료·복구, 시장 개장·마감 알림은 보내지 않는다. 수집 오류 알림과 기존 주문 접수·체결·거절 및 장 마감 보고는 유지한다.

명령 수신은 NATS 연결과 독립적으로 시작한다. 응답 전송이 실패하면 해당 명령을 재시도한 후 Telegram 업데이트 offset을 전진시킨다. 조회 처리 실패도 사용자에게 회신하며 긴 응답은 줄 경계를 기준으로 나누어 마지막 합계가 잘리지 않도록 한다. 조회용 SQLite 연결은 명시적으로 닫는다.

- Linux 격리 컨테이너 관련 통합 테스트 154개 통과.

중단 때문에 발생한 실시간 코인 시세 공백은 남아 있다. 보존된 활성 체결/호가 파일의 마지막·첫 타임스탬프 기준으로 Binance 약 30분 45초, Arcus 약 36분 12초, Grvt 약 36분 11초다. 과거 호가를 재구성하지 않았으며 `unintended_server_decommission` 사유로 공백 원장에 기록했다. 원본 데이터와 기존 거래 원장은 보존됐다.
