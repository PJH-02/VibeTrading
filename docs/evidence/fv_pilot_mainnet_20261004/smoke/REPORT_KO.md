Bybit 주문/취소는 표본 각각 1개, GRVT 주문은 3개다. 안정적인 mainnet p95를 측정한 결과가 아니다. GRVT 취소 지연도 주문 지연으로 대용했다. 2배 지연 시나리오는 같은 공개 데이터와 동결 계수를 사용했다.

지연 후 관측한 호가가 주문 가격과 교차하면 PostOnly 의도를 거절한다. Maker는 활성화 때 표시 잔량 전부를 앞선 대기열로 두며, 이후 확인한 반대 방향 거래량만 사용한다. 호가 터치·표시 잔량 감소를 체결로 취급하지 않고 취소량에 따른 queue 개선도 가정하지 않는다. 알려진 가격을 실제 거래가 넘어가면 가격 우선순위를 적용하되 해당 거래량까지만 가정 체결한다. 관측 깊이 밖은 빈 queue로 처리하지 않는다. IOC 감축은 지연 후 관측 L2 깊이를 보호 가격까지 소진하고 부분 체결을 허용한다. 동일 book 버전의 소진량을 재사용하지 않는다.

모의 주문은 실제 호가창에 존재하지 않으므로 외부 잔량에서 빼지 않는다. public 체결 수신 때 모의 재고를 갱신하며 private 체결 통지 지연은 별도 모델링하지 않았다. 공개 데이터와 실제 주문이 서로 영향을 주지 않는다는 가정이 포함된다.
