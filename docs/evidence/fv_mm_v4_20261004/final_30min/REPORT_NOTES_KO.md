## 이번 실험의 해석

최종 평가에서는 네 전략을 두 거래소의 독립 경로로 각각 1800.96초 실행했다. Bybit S4의 XRP 매수 주문 1건이 접수됐고 목표 변경 후 미체결 취소됐다. 나머지는 신규 주문이 없었다. 8개 경로 모두 체결·순손익·수수료·funding은 0이며, 종료 대사에서 두 계정의 잔여 포지션과 미체결 주문은 모두 0이었다. 따라서 이번 30분 결과는 체결 수익성을 입증하지 않는다.

Bybit S2의 학습 lambda가 음수였고, GRVT S3·S4는 보정 자료가 부족해 해당 세 경로의 신규 진입을 막은 상태로 데이터를 수집했다. 실행 정책의 비용·수량 한도를 충족해야 나머지 경로도 주문을 제출한다. Bybit S1에서 비용 기준을 넘은 1초 표본 19개는 D=0.001~0.0085 BTC였고, 깊이 참여 한도 10%를 적용한 수량 0.0001~0.00085 BTC는 주문 단위 0.001 BTC로 내림하면 모두 0이다. 이는 시작 equity와 기록된 표본을 사용한 재구성이며, 모든 실시간 결정의 거절 사유를 재구성한 결과는 아니다. Bybit S3와 GRVT S2의 최대 표본 edge/C는 각각 0.540, 0.875였다. Bybit S4의 짧은 주문 기회는 1초 진단 표본에 남지 않았으므로 표본상 기준 초과가 0이라는 사실과 주문 1건은 모순되지 않는다.

Bybit BTC의 큰 가격 이동과 얕고 넓은 호가 구간은 OFI 오차에 큰 영향을 주었다. 테스트넷 자료의 특성이며 동일한 수치가 실거래 시장에서도 나타난다고 가정하지 않는다. 위 p값과 CI는 짧은 구간의 탐색적 블록 분석이다. 종목도 서로 달라 전략의 우열이나 인과관계로 해석하지 않는다. 10·60초 결과는 보조 진단이며 30초 주 결과를 대체하지 않는다.

GRVT private 연결 공백 7건은 재연결·REST 대사로 복구됐고 최종 미확인 주문은 없었다. Bybit S4의 receive→live 대용 관측은 1개, 0.325초다. 한 값에서 계산된 분위수를 안정적인 p95 지연으로 해석하지 않는다.

## 최종 평가 전에 중단한 실행 점검

GRVT 주문 최소 단위와 취소 TTL 형식을 실제 API로 점검하는 과정에서 앞선 실행들을 중단하고 수정했다. `min_size`를 주문 단위로 사용하고 `time_to_live_ms`를 문자열로 전송하는 수정 후 위 최종 30분 평가를 새 출력 폴더에서 다시 수행했다. 업로드 실패로 이전 릴리스가 실행된 59초 시도도 중단했으며 최종 실행에서는 로컬·서버 소스 해시 일치를 확인했다.

216.78초 평가 후 종료한 실행 점검에서는 GRVT S2가 ETH 0.055개를 maker 매수하고 IOC reduce-only로 감축했다. 주문 4건, 실제 체결 2건, 완전 왕복 1회, 수수료 0.066502 USDT, 수수료 차감 순손익 **+0.113898 USDT**였다. 보유시간은 122.64초였으며 정상 maker 청산이 아닌 강제 감축이다. 이 거래와 손익은 최종 30분 성과에 합치지 않았다. 별도 원장과 보고서를 `interrupted_execution_check`에 보관했다. 다른 두 중단 시도의 체결과 순손익은 0이다. 모든 중단 시도에서도 종료 대사 후 잔여 포지션·주문이 0임을 확인했다.
