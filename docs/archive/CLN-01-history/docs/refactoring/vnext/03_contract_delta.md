## 확정된 불변조건과 승인할 변경

이미 사용자 확정: NATS 제거, 신규 broker/DB 서버 없음, >30분 독립, C3/KP/KD·Mock/Mock2·현재 수집범위 보존, Policy A, FULL, 비활성 전략 유지, KR hotfix 제외. 이 항목을 다시 선택 문제로 만들지 않는다.

이 문서의 C03~C09 명료화/보완, checkpoint 포맷, 계좌 lease 경로, 명령 범위/return 정의는 **후속 구현 기준으로 승인할 제안**이다. A2/A3 기본 활성화·위험 축소 정책 확장·운영 삭제는 포함하지 않는다. C01~C07의 기존 hard gate와 p99/용량 목표를 낮추지 않는다.

원 계약의 일부 과거 현황 설명은 이미 구현된 상태와 다르다. 이를 이유로 원문을 덮어쓰지 않고 [conflict_register](conflict_register.md)에 연결한다.
