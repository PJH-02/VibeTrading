실제 잔고는 두 계좌를 각각 조회하고 전략 장부의 물리적 보유 수량과 계좌별로 대조한다. 주문 레코드에 `account_scope`를 고정하므로 접수 후 취소, 5초 뒤 시장가 잔량 주문, 체결 조회도 동일 계좌를 사용한다. 두 계좌에서 같은 주문번호를 반환해도 계좌가 섞이지 않는다. 계좌별 앱키를 포함한 기존 토큰 캐시 식별자로 캐시도 분리된다. mock2 자격증명이 없으면 mock/실계좌 자격증명으로 대체하지 않는다.

전략 자금은 기존 주 모의계좌의 자금을 C3/KP/KD에 3등분한 기준을 유지한다. 두 번째 계좌의 잔고를 추가해 전략 자금을 두 배로 늘리지 않는다. 실제 주문 수량은 선택한 계좌의 매수가능수량으로 제한된다. 검증 당시 두 번째 계좌의 평가액은 약 1천만원이므로 이 계좌로 가는 전략 주문은 해당 자금 한도에 영향을 받는다.

서버·로컬 `.env`의 `KIS_MOCK2_ACCOUNT_PRODUCT_CODE=01` 뒤 인라인 주석을 별도 줄로 옮겼다. Docker env_file은 인라인 주석을 값의 일부로 취급하여 상품코드가 `01  # ...`로 전달됐기 때문이다. 키·비밀키·계좌번호 값은 변경하거나 출력하지 않았다.

## 가정 손익

실제 체결 장부와 별도 `assumed_fills`를 사용한다. 계좌 권한 관련 명시적 거절만 대상으로 하며, 알려진 `40070000 / 매매불가 종목` 또는 거래권한·거래약정 미등록 등 좁은 사유를 분류한다. 시간 외, 증거금 부족, 일반 주문 오류, 정상 접수 후 미체결, 네트워크 결과 불명은 가정 체결로 바꾸지 않는다.

주문 의도 작성 시 신선한 호가와 시각을 저장한다. 권한 거절이 확인되면 그 기록의 매수는 best ask, 매도는 best bid를 적용한다. 지정가 주문 가격이나 뒤의 1분봉 종가를 가정 체결가로 사용하지 않는다. 10초 이내의 호가 증거가 없으면 임의 가격으로 채우지 않는다.

가정 포지션은 전략의 기존 청산·안전손절 규칙을 따라 계산한다. 가정 진입만 있는 수량을 실제 계좌로 매도하지 않는다. 실제 계좌에 남은 보유와 가정 평가 수량도 분리하므로 물리적 계좌 잔고를 조작하지 않는다. 실제 미체결·불확실 주문은 계속 별도 대사한다. 중복 조회·재시작은 같은 가정 체결을 다시 기록하지 않는다.

가정 수수료는 `ETF_ASSUMED_FEE_RATE`, 기본 0.000148(편도 0.0148%)의 추정값이다. [한국투자증권 모의투자 안내](https://vts3.koreainvestment.com/vts/)의 공개 ETF 수수료 안내를 참고한 값이며, 실제 계좌가 반환한 제비용이나 원 단위 절사까지 동일하다고 주장하지 않는다. 장 마감에는 실제 제비용과 가정 수수료를 구분한다.

## 장 마감 메시지

정규장 15:35부터 거래소 달력으로 실제 마감을 확인한 뒤 두 계좌를 조회한다.

1. 계좌별/합산 실제 평가액 증감과 KIS 제비용.

실제 평가액 증감에는 평가손익·별도 수동 거래·자금 변경도 영향을 줄 수 있으며, 이를 메시지에서 계좌 평가액 기준으로 명시한다. 가정 보유가 남으면 실제 마감 현재가로 평가하고 전일 가정 보유 평가액을 차감한다. 실제 보고와 가정 보고를 하나의 실제 체결 성과로 표현하지 않는다.
